# How to Run - CloudOps Automator (ap-south-2)

1. Linux Lab: ./scripts/linux-lab.sh
2. Docker: cd docker && docker build -t cloudops . && docker run -p 8080:80 cloudops
3. Terraform: cd terraform && terraform init && terraform plan
4. GitHub Actions: Auto runs on push to main
Region: ap-south-2 (Hyderabad)
